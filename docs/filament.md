# Zeus Inline Chart

Inline Chart is to easily add a chart in filamentPHP table column

## Features

- 🔥 Use any filament chart classes
- 🔥 Better tooltip
- 🔥 Use any widget type
- 🔥 Max Width
- 🔥 Polling
